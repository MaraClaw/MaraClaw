# Web fonts

These are the unmodified Google Fonts WOFF2 subsets for **Instrument Sans v4**
and **Inter v20**, normal style, variable weights 400 through 700. Both families
are licensed under the SIL Open Font License 1.1; the complete upstream texts
and copyright notices are included in `instrument-sans-OFL.txt` and
`inter-OFL.txt`.

- Instrument Sans: Copyright 2022 The Instrument Sans Project Authors
  (<https://github.com/Instrument/instrument-sans>).
- Inter: Copyright 2020 The Inter Project Authors
  (<https://github.com/rsms/inter>).

## Official sources

CSS retrieved on 2026-11-15 with a modern Chromium User-Agent:

<https://fonts.googleapis.com/css2?family=Instrument+Sans:wght@400..700&family=Inter:wght@400..700&display=swap>

`fonts.css` preserves its nine variable faces, `font-display: swap`, and exact
Unicode ranges. Each subset is requested only when its characters are used.
Existing application font families and system fallbacks remain in `src/index.css`.
